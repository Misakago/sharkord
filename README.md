# Mikotord

Mikotord is a self-hosted chat platform focused on text, images, and file attachments.

## Development

```bash
bun install
bun run --filter @mikotord/server dev
bun run --filter client dev
```

## Runtime

The server listens on port `4991` by default. The development client listens on
port `5173` by default.
